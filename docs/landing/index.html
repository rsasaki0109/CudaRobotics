⇄

GPUとCPU、どれくらい違う？

各デモの「Compare GPU / CPU」で、同じ入力・計算量の処理時間を比較できます。GPU非対応の端末ではCPUで動作します。

ブラウザ版はWebGPUとJavaScriptの比較です。ネイティブCUDAの性能測定ではありません。
