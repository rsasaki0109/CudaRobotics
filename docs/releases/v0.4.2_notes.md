# v0.4.2 - CudaNav Docker Smoke Exit Fix

CudaRobotics v0.4.2 is a patch release of v0.4.1. It fixes the published
Docker image's `cudanav` mode, which completed the closed-loop mission but
never exited. Python and ROS 2 functionality is unchanged under version 0.4.2.
This is a pre-1.0 release; the separate v1.0 support contract is not declared
ready by this release.

## Fixes

- **`cudanav` exits after the mission.** The entrypoint started `ros2 launch`
  as a background job of a non-interactive shell, which inherits SIGINT as
  ignored, so the cleanup `kill -INT` had no effect and `wait` blocked forever
  before the summary was printed. The launch now runs under job control, so
  SIGINT is delivered and the launch tree has its own process group; if it has
  not stopped 30 seconds after SIGINT, the entrypoint sends TERM and then KILL
  to that group.

No CUDA kernel, Python API, ROS 2 interface, browser demo, or controller
benchmark behavior changes relative to v0.4.1.

## Install

The Python distribution targets Linux x86_64 and CPython 3.10 or 3.12:

```bash
python -m pip install ./cudarobotics-0.4.2-*.whl
```

The Docker image runs the Nav2 controller benchmark by default and the short
CudaNav closed loop with `cudanav`:

```bash
docker run --rm --gpus all ghcr.io/rsasaki0109/cuda-mppi-controller-demo:v0.4.2
docker run --rm --gpus all -v "$PWD/out:/out" \
  ghcr.io/rsasaki0109/cuda-mppi-controller-demo:v0.4.2 cudanav
```

ROS 2 packages target Jazzy / Ubuntu 24.04 with CUDA 12.6. The Colab notebook
in this source release is pinned to the immutable `v0.4.2` tag.

## Verification and limitations

Distribution files are attached only after their exact-tag workflows pass and
the archives are independently re-verified; the image is claimed only after
the tag-triggered Docker workflow succeeds. Before tagging, a locally built
image completed the `cudanav` smoke on a physical GPU and exited 0 in 44 s.
That run is a smoke check, not new release evidence. Existing partial or
negative native and real-dataset evidence is unchanged.
