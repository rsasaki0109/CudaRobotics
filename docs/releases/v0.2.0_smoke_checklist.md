# v0.2.0 Release Smoke Checklist

This checklist is the authoritative pre-tag gate for v0.2.0. Publishing and
tag creation remain separate, explicit release actions.

## Release Target

- Tag: `v0.2.0`
- Base branch: `master`
- Release notes: [`v0.2.0_notes.md`](v0.2.0_notes.md)
- Python and ROS package version: `0.2.0`

## Required Checks

| Check | Command / evidence |
|---|---|
| Version synchronization | `python3 scripts/test_version_consistency.py` |
| Python syntax and CPU utilities | `ctest --test-dir build --label-regex python --output-on-failure` |
| Python package tests | `pytest python/tests -q` |
| Registration GPU consistency | `pytest python/tests/test_registration_consistency.py -q` on an NVIDIA runner |
| Registration suite smoke | `python3 scripts/run_registration_suite.py --algorithms cudarobotics_filterreg_gpu --scenarios lumpy_partial --sizes 512 --trials 1 --strict` |
| Real-rosbag report gate | `python3 scripts/evaluate_mppi_rosbag.py <run.db3> --diagnostics-csv <diagnostics.csv>` |
| Root CUDA build | `cmake -B build && cmake --build build -j` |
| ROS2 CUDA MPPI compile and tests | `.github/workflows/ros2_cuda_mppi.yml` |
| Python sdist and wheels | `.github/workflows/python-package.yml` |
| Whitespace | `git diff --check` |

## Required Artifacts

- `cudarobotics-0.2.0.tar.gz`
- CPython manylinux x86_64 wheels produced by the package workflow
- Registration suite CSV and Markdown from the release candidate commit
- At least one real-rosbag evaluation JSON and Markdown report
- GitHub release notes from `v0.2.0_notes.md`

Do not mark the release ready when a GPU check was merely skipped. Record the
GPU model, driver, CUDA version, command, and output location for both the
registration and rosbag evaluations.
