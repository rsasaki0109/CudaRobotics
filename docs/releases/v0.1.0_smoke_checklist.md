# v0.1.0 Release Smoke Checklist

Date: 2026-06-11 JST

This checklist captures the minimum checks for the first public CudaRobotics
release. It intentionally keeps PyPI out of scope; v0.1.0 is distributed through
GitHub release assets, source builds, Colab, and the GHCR demo image.

## Release Target

- Tag: `v0.1.0`
- Base branch: `master`
- Release notes: [`v0.1.0_notes.md`](v0.1.0_notes.md)
- Python package artifact run: `27308990292`

## Required Checks

| ROS2 CUDA MPPI compile CI | GitHub Actions `ROS2 CUDA MPPI` on PR #189 | Pass |

because the manylinux wheels are the portable release assets.

## Publish Commands

```bash
git fetch origin
git tag v0.1.0 origin/master
git push origin v0.1.0

gh release create v0.1.0 \
  --title "v0.1.0 - Nav2 GPU MPPI plugin, Python package, Colab & Docker" \
  --notes-file docs/releases/v0.1.0_notes.md \
  /tmp/v010_wheels/cudarobotics-manylinux-wheels/*.whl \
  /tmp/v010_wheels/cudarobotics-wheels/cudarobotics-0.1.0.tar.gz
```

Pushing the tag also triggers `.github/workflows/docker-image.yml`, which builds
and pushes `ghcr.io/rsasaki0109/cuda-mppi-controller-demo:v0.1.0` and `latest`.
